# Part 1: Introduction to React

Three small React apps built with Vite.

| Exercises | Project | What it does |
| --- | --- | --- |
| 1.1–1.5 | [`courseinfo/`](courseinfo) | Course information page built from components and props; shows the total number of exercises |
| 1.6–1.11 | [`unicafe/`](unicafe) | Feedback app (good / neutral / bad) with a statistics view |
| 1.12–1.14 | [`anecdote/`](anecdote) | Shows random anecdotes, lets you vote, and displays the most-voted one |

## Running

```bash
cd <project>
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run lint`, `npm run preview`.
