# Part 2: Communicating with the server

React frontends that fetch and modify data on a server with Axios.

| Exercises | Project | What it does |
| --- | --- | --- |
| 2.1–2.5 | [`Render-Collections/`](Render-Collections) | Course information app that renders collections and is split into modules |
| 2.6–2.17 | [`Phone Book/`](<Phone Book>) | Phonebook: add, filter, delete and update contacts, with data stored through json-server |
| 2.18–2.20 | _to be added_ | Data for countries |

[`part2-notes-frontend/`](part2-notes-frontend) is the notes app from the course material, included for reference. It is not part of the exercises.

## Running

```bash
cd <project>
npm install
npm run dev
```

The phonebook needs json-server running in a second terminal:

```bash
npm run server    # serves db.json on port 3001
```
