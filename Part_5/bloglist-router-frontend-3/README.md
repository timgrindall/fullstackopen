# Bloglist Frontend

A React blog frontend built with Vite. Sign in to create blog posts, browse entries, and like your favorites. Designed as part of the Full Stack Open course by the University of Helsinki; pairs with the blog-list-app backend.

Note on Version 3: This is the version where I am going to add a styling library to change how the app is styled (MaterialUI).

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Technologies

- React 18
- Vite
- Axios
- ESLint
